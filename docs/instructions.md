# Issue Tracker Instructions

This folder contains the UI issue inventory and its evidence-based progress assessments.

- Keep all 301 source issues listed by ID with their canonical HTTPS links. Omit non-English titles instead of inventing translations.
- Preserve the three-column tracker shape: issue, fix commit, and assessment.
- Credit a fix only when the target code or a repository fix commit provides evidence; do not infer resolution from an upstream closed state.
- Mark non-UI issues as out of scope, and explain why unresolved UI issues remain open.
- Write repository-authored text in English. Update the tracker in the same commit as each issue-related code change.
